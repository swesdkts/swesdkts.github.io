description: > 
 Poker Friends is a Jackbox-inspired multiplayer Texas Hold’em game built in Unity, designed for local social play using players’ phones as controllers. I implemented a WebSocket-based system where a browser client acts as each player while the Unity application functions as the authoritative dealer, managing card distribution, game state, and rule enforcement. The project demonstrates real-time networking, client–server architecture, and user-focused design aimed at removing physical space and equipment constraints from traditional tabletop games
